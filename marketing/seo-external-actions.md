## Search Console

Use Google Search Console: `https://search.google.com/search-console`

Recommended setup:

1. Add a domain property for `roofsignal.nl`.
2. Verify through DNS TXT in the DNS provider.
3. Submit sitemap: `https://www.roofsignal.nl/sitemap.xml`.
4. Inspect and request indexing for:
   - `https://www.roofsignal.nl/`
   - `https://www.roofsignal.nl/dakinspectie-apeldoorn`
   - `https://www.roofsignal.nl/dakinspectie-vve`
   - `https://www.roofsignal.nl/drone-dakinspectie`
   - `https://www.roofsignal.nl/nen-2767-gebouwschil`
   - `https://www.roofsignal.nl/mjop-input-vve`
   - `https://www.roofsignal.nl/gebouwdata-vastgoedonderhoud`

Fallback if DNS access is slower:

- Add a URL-prefix property for `https://www.roofsignal.nl/`.
- Use HTML-file verification. If Google provides a file like `google123abc.html`, add it to the repo root and deploy.
- Then submit the same sitemap.
